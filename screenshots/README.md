# Archived upstream screenshots

The PNGs in this directory were inherited from the original Codex Subscription
Router. They show the earlier subscription-pooling UI, combined statistics,
plugin account picker, and depletion/reset dialogs.

They are **not screenshots of Personal & Work 0.3.0**, and do not establish
current compatibility, native appearance, or successful account switching.
Automatic quota failover has been removed from the current router.

Current validation is recorded in
[Personal Work validation](../docs/PERSONAL-WORK-VALIDATION.md). Add new captures
only after testing the current app and removing private identities, device
codes, and conversation content.
